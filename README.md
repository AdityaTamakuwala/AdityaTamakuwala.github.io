## ⚡ Key Highlights & Features

- **Cyber-Dark & Glassmorphic UI:** Modern cyber defense aesthetics with glowing neon accents, radar sweeps, and live telemetry tickers.
- **Interactive SOC Cyber Terminal:** A functional browser-based CLI emulator supporting commands (`whoami`, `cat skills`, `fetch projects`, `ioc-scan`, `contact`).
- **Defensive Security Matrix:** Filterable skill grid highlighting Wazuh SIEM, Microsoft Sysmon, ELK Stack, OSINT feeds, and DevSecOps.
- **Curated Repository Showcase:** Direct integration with public repositories:
  1. [`BankSec-TIP`](https://github.com/AdityaTamakuwala/BankSec-TIP): Finance & Banking Threat Intelligence Platform with ELK Stack.
  2. [`cybersecurity-soc-home-lab`](https://github.com/AdityaTamakuwala/cybersecurity-soc-home-lab): VirtualBox Wazuh SIEM + Sysmon SOC environment.
  3. [`ecommerce-enterprise-devsecops-pipeline`](https://github.com/AdityaTamakuwala/ecommerce-enterprise-devsecops-pipeline): CI/CD pipeline with Checkov IaC and OWASP ZAP DAST.
  4. [`Smart-Attendance-System`](https://github.com/AdityaTamakuwala/Smart-Attendance-System): Python biometric anti-spoofing & intrusion detection.
  5. [`RapidCart-Platform`](https://github.com/AdityaTamakuwala/RapidCart-Platform): Full-stack MERN with Razorpay cryptographic verification.
- **1-Click Contact & Connect:** Instant clipboard email copying and direct links to LinkedIn and GitHub.
